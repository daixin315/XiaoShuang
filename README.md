# 🐟 小双桌面宠物（XiaoShuang）

一个跨平台（Linux / Windows / macOS）的桌面 AI 陪伴形象：**AI 生成的古风少女常驻你的桌面**，支持表情切换、动作视频、文字对话、记忆系统、桌面观察帮助、待办提醒。

## ✨ 功能特性

- **双独立窗口**：视频窗口（形象表演）+ 对话窗口（聊天），一键互切
- **AI 对话**：接入任意 OpenAI 兼容 API（默认 DeepSeek），对话模型/视觉模型可分开配置
- **表情与动作**：17 个表情 + 10 个动作动画（1280x720），按钮或输入 `/` 弹出菜单，AI 回复可自动选表情表演
- **记忆系统**：六层记忆（核心/系统/重要/时间线），对话后自动总结，支持 `/记`、`/记忆`、`/忘` 命令
- **桌面观察帮助**：`🔍 帮助` 立即分析当前屏幕给建议；`💡 实时帮助` 持续观察，需要帮助才提醒（视觉模型看图）
- **待办提醒**：说"记一下 明天上午10点开会"，到点提醒
- **关窗保护**：点 X 隐藏到托盘，托盘恢复（不退出）
- **本地 HTTP 接口**（127.0.0.1:8721）：/chat 转达消息、/exec 安全执行命令、/action 点播动作、/status 状态
- **语音播报**：回复可朗读（Edge TTS），待办/帮助提醒出声

## 🖥️ 运行环境

| 平台 | 支持 | 说明 |
|------|------|------|
| Linux | ✅ | systemd 常驻、托盘（appindicator）、Wayland/X11 |
| Windows | ✅ | 绿色免安装版（双击 XiaoShuang.exe）|
| macOS | ⚠️ | 代码兼容，未完整测试 |

依赖：Go 1.22+ 编译；运行需要 `ffmpeg`（播放动画）；对话需要 API Key（DeepSeek 等）。

## 🚀 快速开始

```bash
# 1. 克隆仓库（素材包另见 Releases）
git clone https://github.com/daixin315/XiaoShuang.git
cd XiaoShuang

# 2. 放入素材（见下文"素材"章节）或先跑起来看默认界面
# 3. 编译运行
go build -o XiaoShuang .
./XiaoShuang
```

**配置**：首次启动点 `⚙️ 设置`：

| 设置项 | 说明 |
|--------|------|
| **💬 对话模型** | 聊天用模型：API 地址（如 `https://api.deepseek.com/v1`）、API Key、模型名（如 `deepseek-v4-flash`），OpenAI 兼容接口均可 |
| **👁️ 视觉模型** | 帮助看图用模型（独立配置）：API 地址、Key、模型名（如 `deepseek-v4-flash-vision-exp`）。**地址/Key 留空时自动回退对话模型配置**，只需填模型名 |
| ✏️ 基本人设 | 小双的系统提示词（默认"温柔可爱的少女小双"），可自定义 |
| ✏️ 帮助设置 / 实时帮助设置 | 帮助分析提示词（默认规则见下），可自定义，点"默认"恢复原始文本 |
| 帮助观察间隔 | 实时帮助的截图分析间隔（秒）|

### 帮助功能（默认规则）

- **🔍 帮助**：点击立即分析当前桌面 → 给建议（只分析一次）
- **💡 实时帮助**：持续观察桌面，画面有变化且需要帮助时才提醒

默认判断规则（可修改）：
1. **外语沟通翻译**：如果用户在与人聊天（微信/QQ/邮件等），对方语言不是中文——直接给出【对方消息的中文翻译】+【用对方语言回复的建议内容】，不用问"要不要翻译"
2. **炒股风险分析**：如果用户在炒股/看K线/看行情走势——给出简短的风险分析（大盘/个股走势风险提示）

## 🤖 与 Hermes（AI 助手）联动

小双可以嵌入 [Hermes Agent](https://hermes-agent.nousresearch.com) 工作流，通过 QQ / 本地接口联动：

- **QQ 遥控**：QQ 发 `小双 xxx` → Hermes 转达给小双聊天/表演动作
- **HTTP 接口**（127.0.0.1:8721）：
  - `/chat` 转达消息（与窗口输入完全一致，走同一对话链路和记忆系统）
  - `/action` 点播表情/动作
  - `/mood` 设置情绪
  - `/status` 状态查询
  - `/exec` 执行命令（详见下）

### /exec 命令执行（三重安全防护，无需人工确认）

```
POST http://127.0.0.1:8721/exec
Body: {"cmd": "ls -la"}
返回: {"ok": true, "output": "命令输出..."}
危险命令返回: {"dangerous": true, "error": "拦截原因"}
```

设计：**AI 安全审查通过后直接执行并返回结果**——不需要人工确认（适合嵌入自动化工作流）。

**三重防护**：
1. **黑名单硬拦截**：`rm -rf /`、系统路径删除、`mkfs`、`dd` 写盘、`shutdown`、`passwd` 等危险命令直接拒绝，不经过 AI
2. **AI 安全审查**：所有命令先交给大模型判断是否安全（分析命令意图/参数/影响面），判定危险则拒绝并返回原因
3. **sudo 严格标准**：sudo 命令需满足更高安全标准（明确的可解释操作），密码由程序安全注入（独立文件存储），不暴露在命令中

**使用场景**：小双帮你执行系统操作（查状态、装软件、管理文件），结果直接回传——配合 QQ 遥控就是"远程运维小助手"。
- **本地大模型**：对话模型可填本地 llama.cpp/FreeToken（OpenAI 兼容），如 `http://127.0.0.1:8081/v1`，免 API 费用
